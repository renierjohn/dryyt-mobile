# Drop off v2 (Real-time) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the v1 laundry Drop off with a real-time flow: map search for nearby drivers, accept + customer confirm, live tracking, drop-off form with proof photo, owner confirmation, distance-based fees, payouts.

**Architecture:**
- **Worker:** the Hono Worker in `worker/` gains two Durable Objects.
  - `Dispatch` (one per `group_id`) holds online drivers' live locations and searching requests, and serializes accepts.
  - `Trip` (one per transaction) relays the driver's location to the customer and runs tracking/owner timers.
  - D1 stays the source of truth.
- **Storage:** R2 holds proof photos.
- **Routing:** OpenRouteService gives road distance.
- **Push:** Expo push notifies drivers and owners.
- **Mobile:** the Expo app adds maps (`react-native-maps`), foreground location, a WebSocket hook, and an owner role.

**Tech Stack:**
- Cloudflare Workers, Hono 4, D1, Durable Objects (WebSocket Hibernation API), R2, zod 4
- Vitest 3.2 + `@cloudflare/vitest-pool-workers` 0.8
- Expo SDK 57, Expo Router, TanStack Query 5, `react-native-maps`, `expo-location`, `expo-notifications`, `expo-image-picker`

**Spec:** `docs/superpowers/specs/2026-10-10-dropoff-v2-design.md`. Builds on v1: `docs/superpowers/specs/2026-10-09-delivery-app-design.md`.

## Global Constraints

- Every shell command starts with `export PATH=~/.nvm/versions/node/v22.13.1/bin:$PATH` (system node has no npm/yarn).
- Worker commands run in `worker/`; app commands run in the repo root.
- Worker dev port is `8788` (8787 is taken on this machine).
- Money is integer centavos. Delivery fee formula:
  - `delivery_fee = base_fee + round(road_km × rate_per_km)`
  - `service_fee = round(delivery_fee × commission_pct / 100)`
  - `total_delivery_fee = delivery_fee + service_fee`
- The customer never receives `delivery_fee` or `service_fee`. Drivers and owners do.
- Errors return `{ "error": string }`: 400 validation, 401 auth, 403 role/ownership, 404 missing, 409 conflict/invalid transition, 503 routing unavailable.
- Default timeouts:
  - searching: 3 min
  - customer confirm: 60 s
  - no driver location: 2 min (warn the customer)
  - owner reminder: 30 min
  - driver hidden after 30 s without location
  - location messages faster than 1 per 2 s are dropped
- Matching radius: green ≤ 5 km, amber 5–10 km (straight line). Road distance is used only for the fee (customer → shop).
- Room ids are `crypto.randomUUID()`. WebSocket tickets are single use, 60 s, bound to user + room.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- App: match existing component idioms (`Screen`, `Card`, `Button`, `TextField`, `ErrorText`, `ThemedText`, `Icon`, TanStack hooks in `src/hooks/queries.ts`).

## Spec amendments (applied in Task 1, Step 1)

These resolve gaps found while planning. The spec is updated so it stays the authority.

1. **Driver state is two flags.** `drivers.online` (toggle) and `drivers.busy` (holds a job) replace the 3-value `status`.
   - "open" = online && !busy.
   - Push targets online, not-busy drivers who have no live socket.
2. **Push tokens live on `users.push_token`** (drivers and owners), set by `POST /me/push-token`.
3. **WebSocket tickets are stored in D1** table `ws_tickets`.
4. **Endpoints added:**
   - `GET /dropoffs` (customer's own list)
   - `GET /drivers/me` (`{driver:{online,busy}, job}`)
   - `POST /drivers/me/online`
5. **Verbs:** `PUT` and `DELETE` become `POST`, matching the app's API helper.
   - `POST /me/push-token`
   - `POST /owner/blocks {driver_id, blocked}`
6. **Owner may mark unpaid earlier.** `owner_confirmed → payment_pending` is allowed as well as `completed → payment_pending`.
7. **Customer may cancel during `driver_accepted`** (→ `cancelled`; the driver is released).
8. **One active drop off per customer** (`searching` … `en_route_shop`), enforced by a partial unique index.
9. **Timeout values are code constants** in `worker/src/lib/dropoff-config.ts`. A config table is deferred.
10. **v1 Pickup accept/release/deliver keep `drivers.busy` in sync**, so one active job holds across both flows.
11. **Payouts are unique per `(transaction_id, payee_type)`**, so a double confirm can't double-pay.

## Review Focus

1. **Durable Object hibernation drops in-memory state.**
   - Expected: driver locations survive via socket attachments, and requests survive via storage.
   - Pinned by "rebuilds the driver index after hibernation" (Task 6).
2. **Customer cancels while a driver's accept is in flight.**
   - Expected: exactly one outcome. The driver gets `taken`/`cancelled` and is never left `busy`.
   - Pinned by "cancel racing an accept leaves the driver free" (Task 6).
3. **Double owner confirm or double payment tap.**
   - Expected: second call 409, and payouts are not duplicated.
   - Pinned by "confirming twice does not duplicate payouts" (Task 9).
4. **Fractional km and commission rounding.**
   - Expected: integer centavos, with `total = delivery + service` exactly.
   - Pinned by "rounds fractional distance and commission" (Task 2).
5. **Stranger joins a trip room or reads a proof photo.**
   - Expected: 403 for the ticket and 404 for the photo.
   - Pinned by "only the customer and assigned driver can join a trip" (Task 7) and "hides the proof from strangers" (Task 8).

```ts
  const url = new URL(request.url);
```

```ts
const EARTH_KM = 6371;
const rad = (deg: number) => (deg * Math.PI) / 180;

export function haversineKm(a: LatLng, b: LatLng): number {
  const dLat = rad(b.lat - a.lat);
  const dLng = rad(b.lng - a.lng);
  const h = Math.sin(dLat / 2) ** 2 + Math.cos(rad(a.lat)) * Math.cos(rad(b.lat)) * Math.sin(dLng / 2) ** 2;
  return 2 * EARTH_KM * Math.asin(Math.sqrt(h));
}

const BASE32 = '0123456789bcdefghjkmnpqrstuvwxyz';

export function geohash({ lat, lng }: LatLng, precision = 5): string {
  let latMin = -90;
  let latMax = 90;
  let lngMin = -180;
  let lngMax = 180;
  let hash = '';
  let bits = 0;
  let ch = 0;
  let even = true;
  while (hash.length < precision) {
    if (even) {
      const mid = (lngMin + lngMax) / 2;
      if (lng >= mid) {
        ch = (ch << 1) | 1;
        lngMin = mid;
      } else {
        ch <<= 1;
        lngMax = mid;
      }
    } else {
      const mid = (latMin + latMax) / 2;
      if (lat >= mid) {
        ch = (ch << 1) | 1;
        latMin = mid;
      } else {
        ch <<= 1;
        latMax = mid;
      }
    }
    even = !even;
    bits += 1;
    if (bits === 5) {
      hash += BASE32[ch];
      bits = 0;
      ch = 0;
    }
  }
  return hash;
}

// Precision-5 cell size: 12 latitude bits, 13 longitude bits (~4.9 km × ~4.7 km in Manila).
const CELL_LAT = 180 / 2 ** 12;
const CELL_LNG = 360 / 2 ** 13;

/** Precision-5 cells within `rings` cells of `p` (3 rings ≥ 14 km, so every driver within MAX_KM is included). */
export function nearbyCells(p: LatLng, rings = 3): Set<string> {
  const cells = new Set<string>();
  for (let dy = -rings; dy <= rings; dy++) {
    for (let dx = -rings; dx <= rings; dx++) {
      const lat = Math.max(-90, Math.min(90, p.lat + dy * CELL_LAT));
      const lng = ((p.lng + dx * CELL_LNG + 540) % 360) - 180;
      cells.add(geohash({ lat, lng }));
    }
  }
  return cells;
}

export function distanceColour(km: number): 'green' | 'amber' | null {
  if (km <= NEAR_KM) return 'green';
  if (km <= MAX_KM) return 'amber';
  return null;
}
```

```ts
import type { LatLng } from '../types';

export class RoutingError extends Error {}

type RoutingEnv = { ORS_URL: string; ORS_API_KEY: string };

/** Road distance in km (2 decimals) via OpenRouteService. The only routing call site, so OSRM can replace it later. */
export async function roadDistanceKm(env: RoutingEnv, from: LatLng, to: LatLng): Promise<number> {
  let res: Response;
  try {
    res = await fetch(`${env.ORS_URL}/v2/directions/driving-car`, {
      method: 'POST',
      headers: { authorization: env.ORS_API_KEY, 'content-type': 'application/json', accept: 'application/json' },
      body: JSON.stringify({ coordinates: [[from.lng, from.lat], [to.lng, to.lat]] }),
    });
  } catch (err) {
    throw new RoutingError(String(err));
  }
  if (!res.ok) throw new RoutingError(`OpenRouteService responded ${res.status}`);

  const data = (await res.json()) as { routes?: { summary?: { distance?: number } }[] };
  const route = data.routes?.[0];
  if (!route) throw new RoutingError('No route found');
  return Math.round((route.summary?.distance ?? 0) / 10) / 100;
}
```

```ts
    .map((to) => ({ to, title, body, data, priority: 'high', channelId: 'default', sound: 'default' }));

/** Best effort: a push failure never fails the request that triggered it. */
export async function sendPush(messages: PushMessage[]) {
  for (let i = 0; i < messages.length; i += 100) {
    try {
      await fetch('https://exp.host/--/api/v2/push/send', {
        method: 'POST',
        headers: { 'content-type': 'application/json', accept: 'application/json' },
        body: JSON.stringify(messages.slice(i, i + 100)),
      });
    } catch (err) {
      console.error('push failed', err);
    }
  }
}

export async function pushToUsers(db: D1Database, userIds: number[], title: string, body: string, data?: Record<string, unknown>) {

    .bind(...userIds)
    .all<{ push_token: string | null }>();
  await sendPush(pushMessages(results.map((r) => r.push_token), title, body, data));
```

```ts
  shop_lng: number;
  road_km: number;
  delivery_fee: number;

  total_delivery_fee: number;
  laundry_fee: number | null;
  created_at: string;
  updated_at: string;
  store_name: string;
  store_address: string;
  store_owner_id: number | null;
  store_group_id: string;
  customer_name: string;
  customer_phone: string;
  driver_name: string | null;
  driver_phone: string | null;
  weight_kg: number | null;
  drop_notes: string | null;
  proof_photo_key: string | null;
  owner_status: 'pending' | 'ok' | null;
};

const SELECT = `SELECT t.*,
    s.name AS store_name, s.address AS store_address, s.owner_id AS store_owner_id, s.group_id AS store_group_id,
    cu.name AS customer_name, cu.phone AS customer_phone,
    d.name AS driver_name, d.phone AS driver_phone,
    ot.weight_kg, ot.notes AS drop_notes, ot.proof_photo_key, ot.status AS owner_status
  FROM transactions t
  JOIN stores s ON s.id = t.store_id
  JOIN users cu ON cu.id = t.customer_id
  LEFT JOIN users d ON d.id = t.driver_id
  LEFT JOIN owner_transactions ot ON ot.transaction_id = t.id`;

export async function listDropoffs(db: D1Database, where: string, ...binds: unknown[]) {
  const { results } = await db.prepare(`${SELECT} WHERE ${where}`).bind(...binds).all<DropoffRow>();
  return results;
}

export async function getDropoff(db: D1Database, id: number) {
  return (await listDropoffs(db, 't.id = ?', id))[0] ?? null;
}

/** What `user` may see of a drop off, or null when they have no access. Customers never see the fee split. */
export function viewFor(row: DropoffRow, user: AuthUser) {
  const { proof_photo_key, store_owner_id, store_group_id, delivery_fee, service_fee, room_id, ...rest } = row;
  const shared = { ...rest, has_proof: proof_photo_key !== null };
  if (user.role === 'customer' && row.customer_id === user.id) return { ...shared, room_id };
  if (user.role === 'driver' && row.driver_id === user.id) return { ...shared, room_id, delivery_fee, service_fee };
  if (user.role === 'owner' && store_owner_id === user.id) return { ...shared, delivery_fee, service_fee };
  return null;
}

export type DropoffView = NonNullable<ReturnType<typeof viewFor>>;
```

```ts
import { Hono, type Context } from 'hono';
import { z } from 'zod';

import { requireAuth, requireRole } from '../lib/auth';
import { getDropoff, listDropoffs, viewFor } from '../lib/dropoffs';
import { computeFees, type Rate } from '../lib/fees';
import { fail, parseBody, parseId } from '../lib/http';
import { roadDistanceKm, RoutingError } from '../lib/routing';
import type { AppEnv } from '../types';

const createSchema = z.object({
  store_id: z.number().int().positive(),
  lat: z.number().min(-90).max(90),
  lng: z.number().min(-180).max(180),
  address: z.string().trim().min(1, 'Address is required').max(200),
});

/** The drop off in the URL, or 404 when the caller may not see it. */
async function load(c: Context<AppEnv>) {
  const row = await getDropoff(c.env.DB, parseId(c));
  if (!row || !viewFor(row, c.get('user'))) fail(404, 'Drop off not found');
  return row;
}

async function respond(c: Context<AppEnv>, id: number) {
  const row = await getDropoff(c.env.DB, id);
  return c.json({ dropoff: row && viewFor(row, c.get('user')) });
}

const dropoffs = new Hono<AppEnv>();
dropoffs.use('*', requireAuth);

dropoffs.post('/', requireRole('customer'), async (c) => {
  const input = await parseBody(c, createSchema);
  const db = c.env.DB;

  const store = await db
    .prepare("SELECT id, group_id, lat, lng FROM stores WHERE id = ? AND type = 'laundry'")
    .bind(input.store_id)
    .first<{ id: number; group_id: string; lat: number | null; lng: number | null }>();
  if (!store) fail(400, 'store_id: choose a laundry shop');
  if (store.lat === null || store.lng === null) fail(400, 'store_id: this shop has no map location yet');

  const rate = await db.prepare('SELECT base_fee, rate_per_km, commission_pct FROM rates WHERE group_id = ?').bind(store.group_id).first<Rate>();
  if (!rate) fail(500, 'No rates set for this area');

  let roadKm: number;
  try {
    roadKm = await roadDistanceKm(c.env, input, { lat: store.lat, lng: store.lng });
  } catch (err) {
    if (err instanceof RoutingError) fail(503, "Can't calculate distance, try again");
    throw err;
  }
  const fees = computeFees(roadKm, rate);

  let id: number;
  try {
    const row = await db
      .prepare(
        `INSERT INTO transactions (room_id, customer_id, store_id, customer_lat, customer_lng, customer_address,
           shop_lat, shop_lng, road_km, delivery_fee, service_fee, total_delivery_fee)
         VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?) RETURNING id`,
      )
      .bind(
        crypto.randomUUID(),
        c.get('user').id,
        store.id,
        input.lat,
        input.lng,
        input.address,
        store.lat,
        store.lng,
        roadKm,
        fees.delivery_fee,
        fees.service_fee,
        fees.total_delivery_fee,
      )
      .first<{ id: number }>();
    id = row!.id;
  } catch (err) {
    // transactions_one_active_per_customer
    if (String(err).includes('UNIQUE')) fail(409, 'You already have an active drop off');
    throw err;
  }

  const created = await getDropoff(db, id);
  return c.json({ dropoff: created && viewFor(created, c.get('user')) }, 201);
});

dropoffs.get('/', requireRole('customer'), async (c) => {
  const user = c.get('user');
  const rows = await listDropoffs(c.env.DB, 't.customer_id = ? ORDER BY t.id DESC', user.id);
  return c.json({ dropoffs: rows.map((r) => viewFor(r, user)) });
});

dropoffs.get('/:id', async (c) => respond(c, (await load(c)).id));

dropoffs.post('/:id/cancel', requireRole('customer'), async (c) => {
  const row = await load(c);
  const { meta } = await c.env.DB.prepare(
    "UPDATE transactions SET status = 'cancelled', updated_at = datetime('now') WHERE id = ? AND status = 'searching'",
  )
    .bind(row.id)
    .run();
  if (meta.changes === 0) fail(409, `Cannot cancel a drop off that is ${row.status.replaceAll('_', ' ')}`);
  return respond(c, row.id);
});

export default dropoffs;
```

```ts
import type { AuthUser, Role } from '../types';

const TICKET_TTL_MS = 60_000;

/** Single-use, 60 s ticket so the JWT never appears in a WebSocket URL. */
export async function issueTicket(db: D1Database, user: AuthUser, room: string) {
  const token = crypto.randomUUID();
  const now = Date.now();
  await db.batch([
    db.prepare('DELETE FROM ws_tickets WHERE expires_at <= ?').bind(now),
    db
      .prepare('INSERT INTO ws_tickets (token, user_id, role, room, expires_at) VALUES (?, ?, ?, ?, ?)')
      .bind(token, user.id, user.role, room, now + TICKET_TTL_MS),
  ]);
  return token;
}

export function consumeTicket(db: D1Database, token: string, room: string, now = Date.now()) {
  return db
    .prepare('DELETE FROM ws_tickets WHERE token = ? AND room = ? AND expires_at > ? RETURNING user_id, role')
    .bind(token, room, now)
    .first<{ user_id: number; role: Role }>();
}
```

```ts
import type { AuthUser } from '../types';

/** Which Dispatch group (and, for customers, which drop off) the user may join. */
export async function dispatchAccess(db: D1Database, user: AuthUser): Promise<{ group: string; transactionId?: number } | null> {
  if (user.role === 'driver') {
    const d = await db.prepare('SELECT group_id FROM drivers WHERE user_id = ? AND online = 1').bind(user.id).first<{ group_id: string }>();
    return d ? { group: d.group_id } : null;
  }
  if (user.role === 'customer') {
    const t = await db
      .prepare(
        `SELECT t.id, s.group_id FROM transactions t JOIN stores s ON s.id = t.store_id
         WHERE t.customer_id = ? AND t.status IN ('searching', 'driver_accepted')`,
      )
      .bind(user.id)
      .first<{ id: number; group_id: string }>();
    return t ? { group: t.group_id, transactionId: t.id } : null;
  }
  return null;
}

/** Only the drop off's customer and assigned driver may join its trip room, and only while en route. */
export async function tripAccess(db: D1Database, user: AuthUser, roomId: string): Promise<{ transactionId: number } | null> {
  const column = user.role === 'customer' ? 'customer_id' : user.role === 'driver' ? 'driver_id' : null;
  if (!column) return null;
  const t = await db
    .prepare(`SELECT id FROM transactions WHERE room_id = ? AND ${column} = ? AND status IN ('en_route_pickup', 'en_route_shop')`)
    .bind(roomId, user.id)
    .first<{ id: number }>();
  return t ? { transactionId: t.id } : null;
}
```

```ts
const open: WebSocket[] = [];

/** Ticket + upgrade, then a queue of parsed messages. `next(t)` waits for the first queued message of that type. */
export async function openSocket(token: string, room: string) {
  const { body } = await api('/ws/ticket', { token, body: { room } });
  const path = room === 'dispatch' ? '/ws/dispatch' : `/ws/trip/${room}`;
  const res = await SELF.fetch(`https://api.test${path}?ticket=${body.ticket}`, { headers: { Upgrade: 'websocket' } });
  const ws = res.webSocket;
  if (!ws) throw new Error(`upgrade failed: ${res.status} ${await res.text()}`);
  ws.accept();
  open.push(ws);

  const queue: Msg[] = [];
  ws.addEventListener('message', (e) => queue.push(JSON.parse(e.data as string)));

  return {
    send: (msg: Msg) => ws.send(JSON.stringify(msg)),
    async next(types: string | string[], tries = 200): Promise<Msg> {
      const wanted = Array.isArray(types) ? types : [types];
      for (let i = 0; i < tries; i++) {
        const at = queue.findIndex((m) => wanted.includes(m.t));
        if (at >= 0) return queue.splice(at, 1)[0];
        await new Promise((r) => setTimeout(r, 10));
      }
      throw new Error(`no ${wanted.join('/')} message; queue: ${JSON.stringify(queue)}`);
    },
    close: () => ws.close(),
  };
}

export function closeAll() {
  for (const ws of open.splice(0)) {
    try {
      ws.close();
    } catch {
      // already closed
    }
```

```ts
import { DurableObject } from 'cloudflare:workers';

import { CONFIRM_TIMEOUT_MS, DRIVER_STALE_MS, LOCATION_MIN_INTERVAL_MS, SEARCH_TIMEOUT_MS } from '../lib/dropoff-config';
import { distanceColour, geohash, haversineKm, MAX_KM, nearbyCells } from '../lib/geo';
import { pushToUsers } from '../lib/push';
import type { Bindings, LatLng } from '../types';

export type Message = { t: string; [key: string]: unknown };

export type NewRequest = {
  id: number;
  group: string;
  storeName: string;
  address: string;
  customer: LatLng;
  shop: LatLng;
  deliveryFee: number;
  totalDeliveryFee: number;
  /** Drivers this shop blocked, captured when the request is created. */
  blocked: number[];
};

type DispatchRequest = NewRequest & { status: 'searching' | 'driver_accepted'; driverId?: number; deadline: number };

type DriverAttachment = { role: 'driver'; userId: number; loc?: LatLng; ts?: number };
type CustomerAttachment = { role: 'customer'; userId: number; transactionId: number };
type Attachment = DriverAttachment | CustomerAttachment;

function addTo(cells: Map<string, Set<number>>, cell: string, id: number) {
  const set = cells.get(cell) ?? new Set<number>();
  set.add(id);
  cells.set(cell, set);
}

/**
 * One per group_id. Holds online drivers (location in each socket's attachment, so it survives hibernation)
 * and drop offs that are searching or waiting for the customer to confirm (in storage).
 */
export class Dispatch extends DurableObject<Bindings> {
  private requests = new Map<number, DispatchRequest>();
  /** geohash cell → driver ids. Rebuilt from socket attachments when null (after hibernation). */
  private cells: Map<string, Set<number>> | null = null;

  constructor(ctx: DurableObjectState, env: Bindings) {
    super(ctx, env);
    ctx.blockConcurrencyWhile(async () => {
      for (const r of (await ctx.storage.get<DispatchRequest[]>('requests')) ?? []) this.requests.set(r.id, r);
    });
  }

  /** Socket upgrade. routes/ws.ts has already checked the ticket and set these headers. */
  async fetch(request: Request): Promise<Response> {
    const userId = Number(request.headers.get('x-user-id'));
    const [client, server] = Object.values(new WebSocketPair());

    if (request.headers.get('x-role') === 'driver') {
      this.ctx.acceptWebSocket(server, ['driver', `u:${userId}`]);
      server.serializeAttachment({ role: 'driver', userId } satisfies DriverAttachment);
    } else {
      const transactionId = Number(request.headers.get('x-transaction-id'));
      this.ctx.acceptWebSocket(server, ['customer', `tx:${transactionId}`]);
      server.serializeAttachment({ role: 'customer', userId, transactionId } satisfies CustomerAttachment);
      const r = this.requests.get(transactionId);
      this.send(server, { t: 'drivers', items: r ? this.driversFor(r) : [] });
      if (r?.status === 'driver_accepted') await this.announceDriver(r);
    }
    return new Response(null, { status: 101, webSocket: client });
  }

  async webSocketMessage(ws: WebSocket, data: string | ArrayBuffer) {
    const att = ws.deserializeAttachment() as Attachment;
    if (att.role !== 'driver' || typeof data !== 'string') return;
    let msg: Message;
    try {
      msg = JSON.parse(data);
    } catch {
      return;
    }
    if (msg.t === 'loc') this.onLocation(ws, att, msg);
    else if (msg.t === 'accept' && typeof msg.transaction_id === 'number') await this.accept(ws, att, msg.transaction_id);
  }

  async webSocketClose(ws: WebSocket) {
    await this.dropSocket(ws);
  }

  async webSocketError(ws: WebSocket) {
    await this.dropSocket(ws);
  }

  // ---- RPC from the Worker ----

  async newRequest(r: NewRequest) {
    const req: DispatchRequest = { ...r, status: 'searching', deadline: Date.now() + SEARCH_TIMEOUT_MS };
    this.requests.set(req.id, req);
    await this.save();
    this.refreshDriversNear(req.customer);
    this.ctx.waitUntil(this.pushIdleDrivers(req));
  }

  async removeRequest(id: number, driverMessage?: Message) {
    const r = this.requests.get(id);
    if (!r) return;
    this.requests.delete(id);
    await this.save();
    if (r.driverId && driverMessage) this.toDriver(r.driverId, driverMessage);
    this.refreshDriversNear(r.customer);
  }

  async requeue(id: number) {
    const r = this.requests.get(id);
    if (!r) return;
    if (r.driverId) this.toDriver(r.driverId, { t: 'released', transaction_id: id });
    this.requests.set(id, { ...r, status: 'searching', driverId: undefined, deadline: Date.now() + SEARCH_TIMEOUT_MS });
    await this.save();
    this.toCustomer(id, { t: 'searching' });
    this.refreshDriversNear(r.customer);
  }

  // ---- Timeouts ----

  async alarm() {
    const now = Date.now();
    const db = this.env.DB;
    for (const r of [...this.requests.values()]) {
      if (r.deadline > now) continue;
      if (r.status === 'searching') {
        await db
          .prepare("UPDATE transactions SET status = 'expired', updated_at = datetime('now') WHERE id = ? AND status = 'searching'")
          .bind(r.id)
          .run();
        this.requests.delete(r.id);
        this.toCustomer(r.id, { t: 'expired' });
        this.refreshDriversNear(r.customer);
        continue;
      }
      const { meta } = await db
        .prepare(
          "UPDATE transactions SET status = 'searching', driver_id = NULL, updated_at = datetime('now') WHERE id = ? AND status = 'driver_accepted'",
        )
        .bind(r.id)
        .run();
      if (meta.changes === 0) {
        this.requests.delete(r.id); // confirmed or cancelled meanwhile
        continue;
      }
      await db.prepare('UPDATE drivers SET busy = 0 WHERE user_id = ?').bind(r.driverId).run();
      await this.requeue(r.id);
    }
    await this.save();
  }

  // ---- Driver messages ----

  private onLocation(ws: WebSocket, att: DriverAttachment, msg: Message) {
    const { lat, lng } = msg;
    if (typeof lat !== 'number' || typeof lng !== 'number' || Math.abs(lat) > 90 || Math.abs(lng) > 180) return;
    const now = Date.now();
    if (att.ts && now - att.ts < LOCATION_MIN_INTERVAL_MS) return;

    const before = att.loc;
    const loc = { lat, lng };
    this.moveDriver(att.userId, before, loc);
    ws.serializeAttachment({ ...att, loc, ts: now } satisfies DriverAttachment);

    this.send(ws, { t: 'requests', items: this.requestsFor(att.userId, loc) });
    for (const r of this.requests.values()) {
      if (r.status !== 'searching') continue;
      const wasNear = before !== undefined && haversineKm(before, r.customer) <= MAX_KM;
      if (wasNear || haversineKm(loc, r.customer) <= MAX_KM) this.toCustomer(r.id, { t: 'drivers', items: this.driversFor(r) });
    }
  }

  private async accept(ws: WebSocket, att: DriverAttachment, id: number) {
    const taken = () => this.send(ws, { t: 'taken', transaction_id: id });
    const r = this.requests.get(id);
    if (!r || r.status !== 'searching' || r.blocked.includes(att.userId)) return taken();
    if (!att.loc || haversineKm(att.loc, r.customer) > MAX_KM) return taken();

    // D1 decides the race: messages interleave at every await, so the in-memory check above is only a fast path.
    const db = this.env.DB;
    const busy = await db.prepare('UPDATE drivers SET busy = 1 WHERE user_id = ? AND busy = 0').bind(att.userId).run();
    if (busy.meta.changes === 0) return this.send(ws, { t: 'error', message: 'Finish your active job first' });
    const won = await db
      .prepare(
        "UPDATE transactions SET driver_id = ?, status = 'driver_accepted', updated_at = datetime('now') WHERE id = ? AND status = 'searching'",
      )
      .bind(att.userId, id)
      .run();
    if (won.meta.changes === 0) {
      await db.prepare('UPDATE drivers SET busy = 0 WHERE user_id = ?').bind(att.userId).run();
      return taken();
    }

    // The customer may have cancelled while we awaited D1; the cancel route has then already freed the driver.
    const current = this.requests.get(id);
    if (!current) return this.send(ws, { t: 'cancelled', transaction_id: id });

    const held: DispatchRequest = { ...current, status: 'driver_accepted', driverId: att.userId, deadline: Date.now() + CONFIRM_TIMEOUT_MS };
    this.requests.set(id, held);
    await this.save();
    this.send(ws, { t: 'accepted', transaction_id: id });
    await this.announceDriver(held);
    for (const d of this.nearbyDrivers(held.customer)) this.toDriver(d.userId, { t: 'taken', transaction_id: id });
    this.refreshDriversNear(held.customer);
  }

  private async dropSocket(ws: WebSocket) {
    try {
      ws.close(1000, 'bye');
    } catch {
      // already closed
    }
    const att = ws.deserializeAttachment() as Attachment;
    if (att.role !== 'driver' || !att.loc) return;
    const others = this.ctx.getWebSockets(`u:${att.userId}`).filter((s) => s !== ws);
    if (others.length === 0) this.moveDriver(att.userId, att.loc, undefined);
    await this.env.DB.prepare("UPDATE drivers SET lat = ?, lng = ?, updated_at = datetime('now') WHERE user_id = ?")
      .bind(att.loc.lat, att.loc.lng, att.userId)
      .run();
    for (const r of this.requests.values()) {
      if (r.status === 'searching' && haversineKm(att.loc, r.customer) <= MAX_KM) this.toCustomer(r.id, { t: 'drivers', items: this.driversFor(r) });
    }
  }

  // ---- Matching ----

  private index(): Map<string, Set<number>> {
    if (this.cells) return this.cells;
    const cells = new Map<string, Set<number>>();
    for (const ws of this.ctx.getWebSockets('driver')) {
      const att = ws.deserializeAttachment() as Attachment;
      if (att.role === 'driver' && att.loc) addTo(cells, geohash(att.loc), att.userId);
    }
    return (this.cells = cells);
  }

  private moveDriver(id: number, from: LatLng | undefined, to: LatLng | undefined) {
    const cells = this.index();
    if (from) cells.get(geohash(from))?.delete(id);
    if (to) addTo(cells, geohash(to), id);
  }

  /** Latest location of a connected driver (a reconnect can briefly leave two sockets). */
  private driverState(userId: number): DriverAttachment | null {
    let best: DriverAttachment | null = null;
    for (const ws of this.ctx.getWebSockets(`u:${userId}`)) {
      const att = ws.deserializeAttachment() as Attachment;
      if (att.role === 'driver' && att.loc && att.ts && (!best || att.ts > (best.ts ?? 0))) best = att;
    }
    return best;
  }

  private holding(userId: number) {
    for (const r of this.requests.values()) if (r.driverId === userId) return true;
    return false;
  }

  /** Connected, fresh, free drivers within MAX_KM of `p`. */
  private nearbyDrivers(p: LatLng) {
    const now = Date.now();
    const cells = this.index();
    const found: { userId: number; loc: LatLng; km: number }[] = [];
    for (const cell of nearbyCells(p)) {
      for (const userId of cells.get(cell) ?? []) {
        const state = this.driverState(userId);
        if (!state?.loc || now - (state.ts ?? 0) > DRIVER_STALE_MS || this.holding(userId)) continue;
        const km = haversineKm(p, state.loc);
        if (km <= MAX_KM) found.push({ userId, loc: state.loc, km });
      }
    }
    return found.sort((a, b) => a.km - b.km);
  }

  /** What the customer sees: positions and colours only. */
  private driversFor(r: DispatchRequest) {
    return this.nearbyDrivers(r.customer)
      .filter((d) => !r.blocked.includes(d.userId))
      .map((d) => ({ lat: d.loc.lat, lng: d.loc.lng, colour: distanceColour(d.km) }));
  }

  private requestsFor(driverId: number, loc: LatLng) {
    const items = [];
    for (const r of this.requests.values()) {
      if (r.status !== 'searching' || r.blocked.includes(driverId)) continue;
      const km = haversineKm(loc, r.customer);
      if (km > MAX_KM) continue;
      items.push({
        transaction_id: r.id,
        store_name: r.storeName,
        address: r.address,
        lat: r.customer.lat,
        lng: r.customer.lng,
        shop_lat: r.shop.lat,
        shop_lng: r.shop.lng,
        distance_km: Math.round(km * 10) / 10,
        colour: distanceColour(km),
        delivery_fee: r.deliveryFee,
        total_delivery_fee: r.totalDeliveryFee,
      });
    }
    return items.sort((a, b) => a.distance_km - b.distance_km);
  }

  private refreshDriversNear(p: LatLng) {
    for (const d of this.nearbyDrivers(p)) this.toDriver(d.userId, { t: 'requests', items: this.requestsFor(d.userId, d.loc) });
  }

  private async announceDriver(r: DispatchRequest) {
    const driver = await this.env.DB.prepare('SELECT name, phone FROM users WHERE id = ?').bind(r.driverId).first<{ name: string; phone: string }>();
    this.toCustomer(r.id, { t: 'driver_accepted', transaction_id: r.id, driver, total_delivery_fee: r.totalDeliveryFee });
  }

  /** Online, free drivers in this group whose app is closed (no socket), last seen within MAX_KM or never located. */
  private async pushIdleDrivers(r: DispatchRequest) {
    const { results } = await this.env.DB.prepare(
      `SELECT d.user_id, d.lat, d.lng FROM drivers d JOIN users u ON u.id = d.user_id
       WHERE d.group_id = ? AND d.online = 1 AND d.busy = 0 AND u.push_token IS NOT NULL`,
    )
      .bind(r.group)
      .all<{ user_id: number; lat: number | null; lng: number | null }>();
    const ids = results
      .filter((d) => this.ctx.getWebSockets(`u:${d.user_id}`).length === 0 && !r.blocked.includes(d.user_id))
      .filter((d) => d.lat === null || d.lng === null || haversineKm({ lat: d.lat, lng: d.lng }, r.customer) <= MAX_KM)
      .map((d) => d.user_id);
    await pushToUsers(this.env.DB, ids, 'New drop off nearby', `${r.storeName}: open Dryyt to accept.`, { transaction_id: r.id });
  }

  // ---- Plumbing ----

  private async save() {
    await this.ctx.storage.put('requests', [...this.requests.values()]);
    const next = Math.min(...[...this.requests.values()].map((r) => r.deadline));
    if (Number.isFinite(next)) await this.ctx.storage.setAlarm(next);
    else await this.ctx.storage.deleteAlarm();
  }

  private send(ws: WebSocket, msg: Message) {
    try {
      ws.send(JSON.stringify(msg));
    } catch {
      // socket closing
    }
  }

  private toDriver(userId: number, msg: Message) {
    for (const ws of this.ctx.getWebSockets(`u:${userId}`)) this.send(ws, msg);
  }

  private toCustomer(transactionId: number, msg: Message) {
    for (const ws of this.ctx.getWebSockets(`tx:${transactionId}`)) this.send(ws, msg);
  }
}
```

```ts
import { DurableObject } from 'cloudflare:workers';

import { LOCATION_MIN_INTERVAL_MS, NO_LOCATION_WARN_MS, OWNER_REMINDER_MS } from '../lib/dropoff-config';
import { pushToUsers } from '../lib/push';
import type { Bindings, LatLng } from '../types';

type Attachment = { role: 'customer' | 'driver'; userId: number; ts?: number };
type Message = { t: string; [key: string]: unknown };
type Timers = { staleAt?: number; ownerAt?: number };

/** Live tracking room for one drop off (named by its room_id). */
export class Trip extends DurableObject<Bindings> {
  async start(transactionId: number) {
    await this.ctx.storage.put('transactionId', transactionId);
    await this.ctx.storage.put('tracking', true);
    await this.setTimers({ staleAt: Date.now() + NO_LOCATION_WARN_MS });
  }

  async notify(msg: Message) {
    for (const ws of this.ctx.getWebSockets()) this.send(ws, msg);
  }

  /** Laundry is at the shop: stop tracking, remind the owner if they don't confirm. */
  async finish() {
    await this.ctx.storage.put('tracking', false);
    await this.setTimers({ staleAt: undefined, ownerAt: Date.now() + OWNER_REMINDER_MS });
  }

  async stop() {
    await this.ctx.storage.put('tracking', false);
    await this.setTimers({ staleAt: undefined, ownerAt: undefined });
  }

  /** Socket upgrade. routes/ws.ts has already checked the ticket and membership. */
  async fetch(request: Request): Promise<Response> {
    const role = request.headers.get('x-role') === 'driver' ? 'driver' : 'customer';
    const [client, server] = Object.values(new WebSocketPair());
    this.ctx.acceptWebSocket(server, [role]);
    server.serializeAttachment({ role, userId: Number(request.headers.get('x-user-id')) } satisfies Attachment);
    if (role === 'customer') {
      const loc = await this.ctx.storage.get<LatLng>('loc');
      if (loc) this.send(server, { t: 'loc', ...loc });
    }
    return new Response(null, { status: 101, webSocket: client });
  }

  async webSocketMessage(ws: WebSocket, data: string | ArrayBuffer) {
    const att = ws.deserializeAttachment() as Attachment;
    if (att.role !== 'driver' || typeof data !== 'string') return;
    let msg: Message;
    try {
      msg = JSON.parse(data);
    } catch {
      return;
    }
    if (msg.t !== 'loc' || typeof msg.lat !== 'number' || typeof msg.lng !== 'number') return;
    const now = Date.now();
    if (att.ts && now - att.ts < LOCATION_MIN_INTERVAL_MS) return;
    ws.serializeAttachment({ ...att, ts: now } satisfies Attachment);

    const loc = { lat: msg.lat, lng: msg.lng };
    await this.ctx.storage.put('loc', loc);
    if (await this.ctx.storage.get<boolean>('tracking')) await this.setTimers({ staleAt: now + NO_LOCATION_WARN_MS });
    for (const customer of this.ctx.getWebSockets('customer')) this.send(customer, { t: 'loc', ...loc });
  }

  async webSocketClose(ws: WebSocket) {
    try {
      ws.close(1000, 'bye');
    } catch {
      // already closed
    }
  }

  async alarm() {
    const now = Date.now();
    const timers = await this.timers();
    if (timers.staleAt !== undefined && timers.staleAt <= now) {
      await this.setTimers({ staleAt: undefined }); // warn once; the next location re-arms it
      for (const customer of this.ctx.getWebSockets('customer')) this.send(customer, { t: 'stale' });
    }
    if (timers.ownerAt !== undefined && timers.ownerAt <= now) {
      await this.setTimers({ ownerAt: undefined });
      await this.remindOwner();
    }
  }

  private async remindOwner() {
    const id = await this.ctx.storage.get<number>('transactionId');
    const row = await this.env.DB.prepare(
      `SELECT s.owner_id FROM owner_transactions ot JOIN stores s ON s.id = ot.store_id
       WHERE ot.transaction_id = ? AND ot.status = 'pending'`,
    )
      .bind(id)
      .first<{ owner_id: number | null }>();
    if (row?.owner_id) {
      await pushToUsers(this.env.DB, [row.owner_id], 'Drop off waiting', 'A laundry drop off is waiting for your confirmation.', {
        transaction_id: id,
      });
    }
  }

  private async timers() {
    return (await this.ctx.storage.get<Timers>('timers')) ?? {};
  }

  private async setTimers(patch: Timers) {
    const next = { ...(await this.timers()), ...patch };
    await this.ctx.storage.put('timers', next);
    const at = Math.min(next.staleAt ?? Infinity, next.ownerAt ?? Infinity);
    if (Number.isFinite(at)) await this.ctx.storage.setAlarm(at);
    else await this.ctx.storage.deleteAlarm();
  }

  private send(ws: WebSocket, msg: Message) {
    try {
      ws.send(JSON.stringify(msg));
    } catch {
      // socket closing
    }
  }
}
```

```ts
let authToken: string | null = null;

export function setAuthToken(token: string | null) {
  authToken = token;

  onUnauthorized = handler;

export class ApiError extends Error {
  status: number;

  constructor(status: number, message: string) {
    super(message);
    this.status = status;
  }
}

export const apiUrl = (path: string) => `${API_URL}${path}`;
export const wsUrl = (path: string) => `${API_URL.replace(/^http/, 'ws')}${path}`;
export const authHeaders = (): Record<string, string> => (authToken ? { authorization: `Bearer ${authToken}` } : {});

type Options = { method?: 'GET' | 'POST'; body?: unknown };

export function api<T>(path: string, { method, body }: Options = {}): Promise<T> {
  return request<T>(path, {
    method: method ?? (body === undefined ? 'GET' : 'POST'),
    headers: { 'content-type': 'application/json' },
    body: body === undefined ? undefined : JSON.stringify(body),
  });
}

/** Sends a local file (e.g. a camera photo) as the raw request body. */
export async function uploadImage<T>(path: string, uri: string, contentType: string): Promise<T> {
  const blob = await (await fetch(uri)).blob();
  return request<T>(path, { method: 'POST', headers: { 'content-type': contentType }, body: blob });
}

async function request<T>(path: string, init: { method: string; headers: Record<string, string>; body?: string | Blob }): Promise<T> {
  let res: Response;
  try {
    res = await fetch(apiUrl(path), { ...init, headers: { ...init.headers, ...authHeaders() } });
  } catch {
    throw new ApiError(0, 'Cannot reach the server. Check your connection.');
  }

  const data = await res.json().catch(() => ({}));
  if (!res.ok) {
    if (res.status === 401 && authToken) onUnauthorized();
    throw new ApiError(res.status, data.error ?? `Request failed (${res.status})`);
  }
  return data as T;
}
```

```ts
import { useCallback, useEffect, useRef, useState } from 'react';

import { api, wsUrl } from '@/lib/api';

// eslint-disable-next-line @typescript-eslint/no-explicit-any
export type SocketMessage = { t: string; [key: string]: any };

const BACKOFF_MS = [1000, 2000, 5000, 10000];

/** Joins `room` ('dispatch' or a trip room id) with a fresh ticket per attempt; reconnects with backoff. `null` = stay closed. */
export function useSocket(room: string | null, onMessage: (msg: SocketMessage) => void) {
  const [connected, setConnected] = useState(false);
  const socket = useRef<WebSocket | null>(null);
  const handler = useRef(onMessage);

  useEffect(() => {
    handler.current = onMessage;
  });

  useEffect(() => {
    if (!room) return;
    let closed = false;
    let attempt = 0;
    let timer: ReturnType<typeof setTimeout> | undefined;

    const retry = () => {
      if (closed) return;
      timer = setTimeout(open, BACKOFF_MS[Math.min(attempt, BACKOFF_MS.length - 1)]);
      attempt += 1;
    };

    async function open() {
      try {
        const { ticket } = await api<{ ticket: string }>('/ws/ticket', { body: { room } });
        if (closed) return;
        const path = room === 'dispatch' ? '/ws/dispatch' : `/ws/trip/${room}`;
        const ws = new WebSocket(wsUrl(`${path}?ticket=${ticket}`));
        socket.current = ws;
        ws.onopen = () => {
          attempt = 0;
          setConnected(true);
        };
        ws.onmessage = (e) => {
          try {
            handler.current(JSON.parse(String(e.data)));
          } catch {
            // ignore malformed messages
          }
        };
        ws.onclose = () => {
          setConnected(false);
          retry();
        };
      } catch {
        retry();
      }
    }

    open();
    return () => {
      closed = true;
      clearTimeout(timer);
      socket.current?.close();
      socket.current = null;
      setConnected(false);
    };
  }, [room]);

  const send = useCallback((msg: SocketMessage) => {
    if (socket.current?.readyState === WebSocket.OPEN) socket.current.send(JSON.stringify(msg));
  }, []);

  return { connected, send };
```

```ts
import * as Location from 'expo-location';
import { useEffect, useRef, useState } from 'react';

import type { LatLng } from '@/lib/types';

const PERMISSION_ERROR = 'Allow location access to use drop off.';

export function useCurrentLocation() {
  const [loc, setLoc] = useState<LatLng | null>(null);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    let cancelled = false;
    (async () => {
      const { granted } = await Location.requestForegroundPermissionsAsync();
      if (!granted) throw new Error(PERMISSION_ERROR);
      const pos = await Location.getCurrentPositionAsync({ accuracy: Location.Accuracy.High });
      if (!cancelled) setLoc({ lat: pos.coords.latitude, lng: pos.coords.longitude });
    })().catch((err: Error) => {
      if (!cancelled) setError(err.message);
    });
    return () => {
      cancelled = true;
    };
  }, []);

  return { loc, error };
}

/** Calls `onLocation` about every 5 s while `enabled` (foreground only: the app must stay open). */
export function useWatchLocation(enabled: boolean, onLocation: (at: LatLng) => void) {
  const handler = useRef(onLocation);

  useEffect(() => {
    handler.current = onLocation;
  });

  useEffect(() => {
    if (!enabled) return;
    let sub: Location.LocationSubscription | null = null;
    let cancelled = false;
    (async () => {
      const { granted } = await Location.requestForegroundPermissionsAsync();
      if (!granted || cancelled) return;
      sub = await Location.watchPositionAsync(
        { accuracy: Location.Accuracy.High, timeInterval: 5000, distanceInterval: 0 },
        (pos) => handler.current({ lat: pos.coords.latitude, lng: pos.coords.longitude }),
      );
      if (cancelled) sub.remove();
    })();
    return () => {
      cancelled = true;
      sub?.remove();
    };
  }, [enabled]);
}
```
